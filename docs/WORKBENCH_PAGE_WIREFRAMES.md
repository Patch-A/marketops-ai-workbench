# MarketOps AI Workbench 页面线框与首版交付边界

状态：`confirmed information architecture, first shell in implementation`

本文把已确认的六个一级业务页面转换为实现前的低保真界面契约。它只定义页面职责、主要区域、状态和流转，不代表 GEO、资讯、模型或 Obsidian 连接已经可用。

## 1. 页面层级

```text
总控台
项目
  └─ 项目详情：概览 / Brief / 调研 / 方案 / 计划 / 执行 / 复盘
研究与情报
  └─ 资讯 / 研究任务 / 研究报告 / 来源
GEO
  └─ 总览 / 产品与市场 / 查询集 / 快照 / 差距诊断 / 优化任务
内容与资产
  └─ 内容任务 / 草稿 / 分发包 / 资产库 / 生图任务 / Obsidian 知识接口
日程
  └─ 今日 / 本周 / 本月 / 未安排 / 已逾期
设置中心
  └─ 模型 / 任务匹配 / 数据源 / Obsidian / 外部连接 / 工作区安全
```

生图是“内容与资产”的完整工作页，不新增一级导航。模型与连接是设置中心，不占业务导航。

## 2. 总控台线框

```text
顶栏：当前工作区 | 全局搜索 | 新建项目 | 运行研究 | 开始生图 | 主题/设置

今日工作队列（主区域）
  逾期 / 今日 / 等待他人 / 本周重点
  每项显示：来源项目、动作、截止日、阻塞原因、进入来源按钮

重点项目（主区域）
  项目名称 | 类型 | 阶段 | 进度 | 健康状态 | 下一动作 | 截止日

GEO 动态（右侧）          重点资讯（右侧）
  最近快照、变化、缺口       来源、时间、关联项目、处理状态

今日日程（底部）
  时间、任务、来源、状态；无连接时显示明确空态
```

首页只聚合事实和行动入口。正式项目状态、GEO 快照、资讯处理和任务修改必须回到来源页面完成。

## 3. 页面状态契约

每个业务页面都必须支持以下状态，不能只实现成功态：

| 状态 | 页面表现 |
|---|---|
| 空态 | 说明为什么没有数据，并给出创建或连接入口 |
| 加载 | 显示正在读取的对象和取消/重试入口 |
| 部分成功 | 保留已完成结果，列出失败项和继续入口 |
| 成功 | 显示来源、时间、版本和下一步 |
| 需要审核 | 明确模型建议、引用和人工动作 |
| 失败 | 显示稳定错误、请求编号和安全重试入口 |
| 历史只读 | 显示版本、时间和不可编辑原因 |
| 撤回/失效 | 不继续使用陈旧结果，并说明重新运行方式 |

## 4. 第一条纵向路径

```text
总控台 -> 项目 -> Brief/方案 -> 交付物审核 -> WBS/排期 -> 执行
```

当前代码已实现“交付物审核 -> WBS/排期 -> 执行”的核心组件。本轮只增加应用壳、总控台入口和项目工作区归属，不伪造研究、GEO、资讯或模型结果。

## 5. 首版验收

- 左侧一级业务入口固定为总控台、项目、研究与情报、GEO、内容与资产、日程；设置中心可访问但不作为业务页面。
- 总控台默认打开，能显示当前服务器项目、当前执行切片状态和未接入模块的明确空态。
- 项目入口能返回现有审核、排期和执行工作区，已有项目链接和 API 行为不被破坏。
- 移动端不出现横向页面溢出；导航按钮有可识别的图标、文本或无障碍名称。
- 所有未接入的数据源都标记为“尚未连接/尚未配置”，不生成虚构的 GEO 数值、热讯或模型输出。

## 6. 后续实施顺序

1. 应用壳和总控台：项目列表、当前项目状态、待办空态、GEO/资讯空态。
2. 项目详情容器：把现有审核、排期、执行组件放入项目工作流。
3. 模型与连接设置：先实现模型注册和服务端密钥边界，再接入研究任务。
4. 研究与情报：固定来源和人工确认的研究结果。
5. GEO：固定查询集的可复现快照和优化任务。
6. 内容与资产、生图、Obsidian：在连接契约和授权范围明确后逐步接入。

## 7. 总控台交互首版

2026-08-18 已将总控台从静态壳升级为可操作的首版控制台，范围仍限于当前已接入的服务器项目事实。

- 时间范围按钮“今日 / 本周 / 本月”会同步更新重点标题、日程标题和任务范围；任务日期缺失或无法解析时保留为待确认事项，不伪造日期。
- 项目状态筛选“全部 / 进行中 / 已阻塞 / 已归档”会重排服务器项目列表；“进行中”覆盖服务器的 `planning` 与 `active`，筛选后选中项目必须仍属于当前筛选，否则清除选中状态。
- 点击项目行会出现选中摘要和“打开项目”入口；点击任务会进入项目的“排期与执行”工作区。
- 刷新按钮会显示同步中的旋转状态并暂时禁用重复触发；失败时显示稳定错误状态，恢复后再允许重试。
- 页面入口使用轻量 View Transition；项目行、筛选按钮和状态栏仅使用颜色、边框、透明度和位移反馈，不加入装饰性大动效。
- 390px、320px 移动检查保留内部横向滑动容器，但页面 `scrollWidth` 不超过视口；筛选和导航容器隐藏滚动条以保持可读性。`prefers-reduced-motion` 下停止新增动画。

本轮浏览器验证使用未启动 FastAPI 的本地静态预览，因此确认的是页面交互、空态和错误态，不证明真实项目列表、GEO、资讯或模型连接已可用。
